# Aditya Dubey portfolio

PORTFOLIO WEBSITE — DESIGN & DEVELOPMENT BRIEF

Design and develop a premium, modern, responsive personal portfolio website for Aditya Dubey, a B.Sc. Computer Science student at MIT ACSC, Pune.

The website should combine minimalist dark-mode aesthetics, strong UX, modern frontend development, subtle animations, and professional personal branding.

The final website should feel like a real developer/data professional's portfolio rather than a basic student resume website.

1. WEBSITE PURPOSE

The primary purpose of the website is to:

Introduce Aditya professionally.

Showcase his technical skills.

Present his projects.

Highlight internships and training.

Display certifications.

Explain his career goals.

Demonstrate his interest in Data Analytics, Data Science, Machine Learning, and Software Development.

Help recruiters, companies, mentors, and collaborators quickly understand his profile.

Provide clear ways to contact or connect with him.

The website should be optimized for internship applications, entry-level opportunities, networking, and professional visibility.
